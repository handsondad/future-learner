#### Claude 插件与技能

参考 GitHub 上最受欢迎的 Claude 插件与定制技能整理而来，并持续补充趋势榜上的新项目，按工作场景分为五类。它们的共同点是：让 AI 在动手之前先思考，从而减少返工与 Token 消耗。

**高级编程与工程**

- 👉 [Karpathy CLAUDE.md](https://github.com/multica-ai/andrej-karpathy-skills) - 只有一个文件，四条原则：动手前先想清楚、能简单就简单、只改该改的地方、先定成功标准。最好的检验是：改动的每一行能不能追溯到用户的要求。
- 👉 [Matt Pocock Skills](https://github.com/mattpocock/skills) - 逼着 AI 在写代码之前，先质疑并推敲你的原始开发计划。
- 👉 [ECC](https://github.com/affaan-m/ECC) - Agent 效能优化系统，融合技能、直觉、记忆、安全审查与研究优先的开发流程。
- 👉 [Agent Skills](https://github.com/addyosmani/agent-skills) - 让 AI 继承高级工程师在调试与维护时的好习惯。
- 👉 [Superpowers](https://github.com/obra/superpowers) - 装好后 agent 不会一上来就写代码：先问清需求，写一份细到"没经验、没品味、还不爱写测试的新人也能照做"的计划，坚持先写测试，再由子 agent 逐个任务推进并互相检查。
- 👉 [Ponytail](https://github.com/DietrichGebert/ponytail) - 让 AI 像"屋里最懒的资深开发"，通过深度思考与精准重构写出更少、更精简的代码。
